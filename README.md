# 🏢 Instituto ABDA - Portal Institucional & Gestão

Este projeto consiste no desenvolvimento do website oficial para o **Instituto ABDA**, unindo uma interface institucional moderna a um sistema funcional de gerenciamento. O objetivo principal é criar uma presença digital sólida para a instituição, facilitando a divulgação de seus projetos sociais, história e canais de doação.

### 💻 O Projeto
O sistema foi construído focando na organização e escalabilidade, dividindo-se em duas frentes principais:

1. **Website Institucional:** Apresentação da causa, história e canais de doação para o público externo.
2. **Sistema de Cadastro (API):** Uma funcionalidade de backend dedicada ao registro e controle de usuários, permitindo uma gestão eficiente dos dados da instituição.

### 🛠️ Tecnologias e Conceitos
* **Frontend:** HTML5, CSS3 e transição para arquitetura baseada em componentes (**Angular**).
* **Backend:** Desenvolvimento de **API para Cadastro de Usuários** (foco em persistência de dados e segurança).
* **UI/UX:** Design pensado para o terceiro setor, priorizando acessibilidade e clareza nas informações.
